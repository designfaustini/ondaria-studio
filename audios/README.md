# Áudios de demonstração

Coloque aqui os áudios de exemplo que todas as rádios podem usar (uma subpasta por categoria, por exemplo `Comerciais/`, `Vinhetas/` e `HCerta/`). Para mais detalhes, veja a seção "Áudios de demonstração" no README principal.

- Esta pasta **não vai para o Git**: os áudios podem ser obras de terceiros e o repositório é público. Copie os arquivos direto para o servidor (cPanel › Gerenciador de Arquivos).
- Use apenas áudios que você tem autorização para distribuir a todas as rádios.
- Depois de copiar, abra a Biblioteca (a leitura é automática) ou rode `php bin/console.php demo:sync`.
